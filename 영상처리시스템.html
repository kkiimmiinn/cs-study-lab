Chapter 01 at a glance

영상은 숫자 행렬이다. 화소마다 밝기 숫자가 하나씩 있고, 영상처리는 그 숫자들에 하는 수학 연산이다. 빛은 표본화(칸 수)와 양자화(밝기 단계)를 거쳐 디지털이 된다.

화소 — 영상의 최소 단위

화소 → 영상 → 영상처리, 세 단어면 시작됩니다

화소 (pixel)

영상의 가장 작은 구성 요소. picture element의 줄임말로, 사진을 확대하면 보이는 네모 하나. 0(검정)~255(흰색)의 밝기 숫자를 가진다.

영상처리 (image processing)

어떤 목적을 위해 화소들에 수학적 연산을 가해 변화를 주는 기술. 처리 대상에 따라 아날로그/디지털로 나뉘며 이 과목은 디지털을 다룬다.

쉽게 말하면사진은 밝기 숫자가 빼곡히 적힌 모눈종이입니다. 포토샵 '밝기 +' 버튼은 사실 전교생(모든 화소)에게 똑같이 점수를 더해 주는 것 — 전부 +100 하면 밝아지고, −100 하면 어두워져요.

결과물로 나누는 두 수준

구분결과물예
저수준 영상처리영상잡음 제거, 밝기 조절, 선명화
고수준 영상처리영상의 특성·정보물체 인식, 얼굴 인식
쉽게 말하면결과물만 보면 됩니다. 사진이 나오면 저수준, "이 사람은 김민"처럼 답이 나오면 고수준. "기본적인 영상처리"라 하면 보통 저수준을 가리켜요.

빛이 숫자가 되기까지 — 조명 × 반사율

f(x, y) = i(x, y) × r(x, y)
i(x,y) = 물체에 비친 조명의 세기 · r(x,y) = 표면의 반사 계수(0~1). 표면이 매끄러우면 r이 커서 밝게, 조명이 세면 i가 커서 밝게 찍힌다.
쉽게 말하면같은 얼굴도 스탠드 밑에서 찍으면 밝고(조명 i↑), 벨벳 옷은 빛을 안 돌려줘서 어둡게 나옵니다(반사율 r↓). 사진 밝기 = 조명 × 반사율, 이 곱셈 하나가 형성 모델의 전부예요. 광원이 적외선이면 적외선 영상, X선이면 의료 영상이 됩니다.

표본화와 양자화 — 칸을 나누고 반올림한다

표본화 sampling

연속 신호에서 몇 칸의 값만 취할지 정한다 → 화소 수, 즉 해상도 M×N이 결정. "1,200만 화소"가 바로 이 칸 수.

양자화 quantization

표본값을 몇 단계 밝기로 반올림할지 정한다 → k비트면 L = 2^k 단계. 128.345도 8비트에선 그냥 128.

쉽게 말하면표본화는 모눈종이 칸 수 정하기, 양자화는 색연필 개수 정하기. 칸도 색도 많을수록 원본에 가깝지만 파일이 커집니다. 아래 실험에서 직접 낮춰 보세요 — 왜 옛날 게임 화면이 계단처럼 보였는지 알게 됩니다.

실험 ① 표본화 · 양자화

슬라이더를 움직여 보세요. 칸 수(해상도)와 비트 수(밝기 단계)가 화질을 어떻게 바꾸는지 보입니다.

실험 ② 밝기 연산 (+/−)

모든 화소에 같은 수를 더하거나 빼 보세요 — 1.1절의 '전원 덧셈'을 직접 해 보는 겁니다.
g(x,y) = f(x,y) + 0

0보다 작아지면 0으로, 255를 넘으면 255로 잘라냅니다(클리핑). 너무 밝게 하면 흰색으로 뭉개지는 이유예요.

행렬로 읽는 영상

L = 2^k   ·   S = M × N × k (비트)
k비트 양자화 → 밝기 L단계. 저장 공간 S는 비트 단위 — 바이트로 바꾸려면 8로 나눈다. 예: 1024×768, 256레벨(k=8) → 6,291,456비트 = 768KB.
g(x, y) = T[ f(x, y) ]
모든 영상처리의 일반식. 입력 f에 변환 T를 걸면 출력 g — 밝기 +100도, 얼굴 보정도 전부 "T를 무엇으로 정하느냐"의 문제다. 한 학기 커리큘럼이 곧 T의 목록.

라이브러리 설치와 첫 프로그램

비슷한 이름 함정 — 설치할 것은 opencv-python. opencv-python-headless는 창 표시(imshow)가 빠진 서버용이라 창이 안 뜹니다. matplotlib(그래프용)도 함께 설치해 두세요. numpy는 자동으로 따라옵니다.
import numpy as np
import cv2

image = np.zeros((300, 400), np.uint8)   # 300행 400열 행렬 = 검은 영상
image.fill(200)                          # 모든 화소를 200(회색)으로

cv2.imshow("Window title", image)        # 행렬을 창에 영상으로 표시
cv2.waitKey(0)                           # 키 입력까지 대기
cv2.destroyAllWindows()
쉽게 말하면이 열 줄이 1장의 결론을 그대로 보여줍니다 — 영상 = 행렬(np.zeros), 처리 = 행렬 연산(fill), 그리고 np.uint8이 바로 8비트 양자화(0~255)의 구현. 회색 창이 뜨면 개발 환경 구축 성공입니다.

값을 담는 네 가지 그릇

리스트 [ ]

추가·삭제·변경 자유. 자유로운 줄 세우기. insert(3,'b')를 하면 뒤 원소가 밀린다.

튜플 ( )

어떤 변경도 불가 — 잠긴 리스트. tuple1[0]=5 는 에러(TypeError).

사전 {키: 값}

이름표 달린 서랍. dict1['email']처럼 키로 접근해 읽고 바꾼다.

집합 set()

중복 없애는 체. 중복 원소는 하나만 남는다. & 교집합, | 합집합, − 차집합.

쉽게 말하면OpenCV에서 이 그릇들을 계속 만납니다 — image.shape가 (행, 열) 튜플이고, 함수 설정값은 리스트·튜플로 넘겨요. "튜플은 왜 못 바꾸게 했지?"라는 의문은 '실수로 바꾸면 안 되는 값'을 지키는 안전장치라고 생각하면 됩니다.

명령행 문법 — 줄을 잇고 나누는 법

문법하는 일예
\ 역슬래시한 명령을 여러 줄로days = (year-1) * ratio + \
[ ] 안 줄바꿈리스트는 \ 없이도 여러 줄 OKmonths = [31, 28, …
; 세미콜론한 줄에 여러 명령day = 7; ratio = 365.2425
, 다중 할당여러 변수 동시 선언year, month = 2020, 1
쉽게 말하면교재 예제는 이 문법으로 "서기 1년 1월 1일부터 2020년 1월 7일까지 며칠?"을 계산합니다 — 답은 737,431일. 1년 평균 365.2425일이라는 그레고리력 상식도 덤으로 얻어 가세요.

연산자 — 헷갈리는 것만 정확히

/ vs // vs %

5/2 → 2.5 (항상 실수) · 5//2 → 2 (몫만) · 5%2 → 1 (나머지). 3**3 → 27 (거듭제곱).

실험 ③ 슬라이스 놀이터

시작·끝·간격을 직접 넣어 보세요. 어떤 원소가 뽑히는지 즉시 색칠됩니다. (빈칸 = 생략)
a[ : : ]
쉽게 말하면이게 중요한 이유 — 영상이 행렬이라 image[100:200, 50:150]이 곧 사진 오려내기(ROI)이고, image[::-1]이 상하 반전입니다. 리스트 자르던 문법이 그대로 사진 편집이 돼요.

조건과 반복 — 파이썬다운 세 가지

# if - elif - else : 블록은 들여쓰기, 헤더 끝은 콜론(:)
if (year % 4==0) and (year % 100 != 0):
    print(year, "는 윤년입니다.")
elif year % 400==0:
    print(year, "는 윤년입니다.")

# while - else : break 없이 끝나야 else 실행 (for-else도 동일)
while n>=0:
    if int(m)==0: break
else:
    print('4 inputs.')

# for의 네 얼굴 — 상황에 맞게 고른다
for i in range(0, 5): ...            # 번호로
for k in kor: ...                    # 원소로
for i, k in enumerate(kor): ...      # 번호+원소
for k, e in zip(kor, eng): ...       # 두 리스트 나란히
쉽게 말하면윤년 규칙 자체가 재밌습니다 — 4년마다 윤년, 그런데 100년마다는 아니고, 400년마다는 또 맞아요. 그래서 2000년은 윤년, 2100년은 평년. 조건문 연습에 이만한 소재가 없죠.

np.zeros((2, 5), np.int32)         # 0으로 채운 2행 5열

쉽게 말하면ndarray의 힘은 일괄 처리입니다. 1,200만 화소 사진을 밝게 하는 데 반복문 1,200만 번이 아니라 image + 100 한 줄. 정수 배열과 실수 배열을 섞으면 결과는 float64로 승격되고, (1, 5)와 (5,)는 서로 다른 shape입니다.
교재 코드 주의 — 교재의 np.int·np.float는 NumPy 1.24(2022)부터 삭제되어 지금 실행하면 AttributeError가 납니다. np.int32, np.float64처럼 구체적으로 쓰세요.
