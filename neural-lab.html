파이썬이 뭐야?

컴퓨터에게 일을 시키는 말(프로그래밍 언어) 중 하나입니다. 사람이 읽기 쉬운 문법 덕분에 전 세계 인공지능 연구의 표준 언어가 됐어요.

우리가 "숫자 세 개를 더해 줘"라고 한국어로 말하듯, 파이썬으로는 sum([1, 2, 3])이라고 씁니다.
= 등호 — "같다"가 아니라 "넣어라"

수학의 =와 다릅니다! 파이썬에서 x = 3은 "x라는 이름의 상자에 3을 넣어라"는 명령입니다. 이 상자를 변수라고 불러요.

w = 0.5 → "w 상자에 0.5를 보관해 둬. 나중에 w라고 부르면 0.5를 꺼내 줄게."
( ) 소괄호 — 기계에 재료 넣기

괄호는 함수(기계)에 재료를 넣는 투입구입니다. print("안녕")은 print라는 출력 기계에 "안녕"이라는 재료를 넣어 작동시키는 것.

Perceptron()처럼 괄호가 비어 있으면 "재료 없이 기본 설정으로 기계를 만들어 줘"라는 뜻입니다.
[ ] 대괄호 — 순서 있는 목록(리스트)

[1, 2, 3]은 숫자 세 개를 순서대로 묶은 목록입니다. 쇼핑 목록이나 출석부처럼요.

y = [-1, 1, 1, 1] → "정답표: 1번 학생은 −1, 2·3·4번 학생은 +1"
[[0,0],[0,1]] — 목록 안의 목록 = 표

대괄호가 두 겹이면 표(엑셀 시트)라고 생각하세요. 바깥 대괄호는 표 전체, 안쪽 대괄호 하나하나가 표의 한 줄(행)입니다.

X = [[0,0],[0,1],[1,0],[1,1]] → 4행 2열의 표. 1번 줄은 (0,0), 2번 줄은 (0,1)… 즉 샘플 4개의 특징을 모은 표.
import — 도구상자 가져오기

남이 미리 만들어 둔 도구상자(라이브러리)를 내 작업대로 가져오는 명령입니다.

import numpy as np → "numpy라는 계산 도구상자를 가져오고, 길으니까 앞으로 np라는 별명으로 부를게."
함수 — 자판기라고 생각하자

함수는 넣으면(입력) 나오는(출력) 자판기입니다. 동전을 넣으면 음료가 나오듯, 값을 넣으면 결과가 나옵니다.

sum([1,2,3]) → sum 자판기에 목록을 넣으면 합계 6이 나온다. p.fit(X, y) → fit 자판기에 문제(X)와 정답(y)을 넣으면 공부를 마친 모델이 나온다.
for 반복문 — "각각에 대해 반복해"

for i in range(10):은 "i를 0부터 9까지 바꿔 가며 아래 일을 10번 반복해라"입니다.

선생님이 "1번부터 30번까지 한 명씩 나와서 발표해"라고 하는 것과 같습니다.
if / while / break

if (조건) = "만약 ~라면 해라". while (true) = "멈추라고 할 때까지 계속 반복해라". break = "반복 그만, 빠져나와!"

"만족스러울 때까지(while) 연습하고, 만족스러우면(if) 그만해라(break)" — §4.3의 수영 배우기 알고리즘이 정확히 이 구조입니다.

라이브러리 — numpy와 sklearn

라이브러리는 전문가들이 미리 만들어 둔 완성품 도구 모음입니다. 요리로 치면 밀키트 — 재료 손질이 다 되어 있어요.

numpy(넘파이) = 숫자 뭉치를 빠르게 계산하는 도구상자. sklearn(사이킷런) = 퍼셉트론·신경망 같은 기계 학습 모델이 완성품으로 들어 있는 도구상자.

보통 리스트를 수학 계산에 최적화된 묶음(배열)으로 바꿔 줍니다. 배열끼리는 x*w처럼 쓰면 같은 자리끼리 한꺼번에 곱해집니다.

np.array([1,2,3]) * np.array([10,10,10]) → [10,20,30]. 반복문 없이 3개가 동시에 곱해졌어요!

벡터 — 숫자 여러 개를 한 줄로 묶은 것

키와 몸무게처럼 관련된 숫자 여러 개를 순서대로 묶으면 벡터입니다. 굵은 글씨(x)로 쓰고, 낱개 숫자는 가는 글씨(x₁)로 씁니다.

철수의 정보 = (키 150cm, 몸무게 45kg) ← 이게 2차원 벡터. 이 랩의 x = (x₁, x₂)도 똑같은 것.
x₁의 작은 숫자(아래첨자) — 그냥 번호표

아래에 붙는 작은 숫자는 계산하라는 게 아니라 "몇 번째"인지 표시하는 번호표입니다.

x₁ = 1번째 특징, x₂ = 2번째 특징. w₀ = 0번째 가중치. 출석번호와 똑같아요.
행렬 — 숫자를 표 모양으로 배열한 것

숫자를 가로줄(행)과 세로줄(열)이 있는 표로 늘어놓은 것. "4×3 행렬" = 가로 4줄, 세로 3칸짜리 표.

반 전체 성적표(학생 30명 × 과목 5개)가 바로 30×5 행렬입니다.
Σ (시그마) — "전부 더해라" 기호

겁먹지 마세요. Σ는 그냥 "아래 번호부터 위 번호까지 다 더해라"는 덧셈 줄임표입니다.

Σi=1..3 i = 1+2+3 = 6.
Σi=1..d wᵢxᵢ = w₁x₁ + w₂x₂ + … + w_d x_d ← "1번부터 d번까지, 가중치×특징을 전부 더해라"
τ, ρ, Δ, ∂, ∇ — 그리스 문자 치트키

수학자들이 즐겨 쓰는 외국 알파벳일 뿐입니다. 이 랩에서 쓰는 것만 외우면 끝:

τ(타우) = 활성 함수 이름 · ρ(로) = 학습률(보폭) · Δw(델타) = "w의 변화량" · ∂(라운드) = 편미분 기호 · ∇(나블라) = 미분값들을 모은 벡터(그레이디언트)
기울기와 미분 — 언덕의 가파름

기울기 = 얼마나 가파른가. 미분 = 어느 한 지점에서의 순간 기울기를 구하는 방법입니다.

자전거로 언덕을 오를 때 "지금 여기가 얼마나 가파르지?"를 재는 것이 미분. 내리막이면 기울기가 음수(−), 오르막이면 양수(+).
편미분(∂) — 손잡이 하나만 돌려 보기

손잡이(변수)가 여러 개일 때, 다른 건 그대로 두고 하나만 살짝 돌렸을 때의 변화를 재는 것입니다.

샤워기의 온도 손잡이와 수압 손잡이 중, 수압은 고정하고 온도 손잡이만 돌리며 "물이 얼마나 뜨거워지나"를 보는 것 = 온도에 대한 편미분.
‖y − o‖ — 두 점 사이의 거리

‖ ‖ 기호는 거리(길이)를 재라는 뜻. 피타고라스 정리로 계산합니다: 차이를 제곱해서 더한 뒤 루트(√).

(0,0)에서 (3,4)까지 거리 = √(3²+4²) = √25 = 5. 신경망에서는 "정답과 예측이 얼마나 떨어져 있나"를 잴 때 씁니다.
e (자연상수) — 2.718…이라는 특별한 수

원주율 π(3.14…)처럼 수학에 자주 등장하는 고정된 수 e ≈ 2.718입니다. ex는 "e를 x번 곱한 것".

시그모이드나 softmax 식에 나오는 e가 바로 이것. 외울 건 "e는 약 2.7인 상수다" 하나면 충분합니다.
확률 — 전체를 1로 놓은 가능성

모든 경우의 가능성을 합치면 딱 1(=100%)이 되도록 나눈 것.

"이 그림이 0일 확률 0.7, 1일 확률 0.2, 2일 확률 0.1" → 합이 1. §4.7의 softmax가 신경망의 출력을 이렇게 만들어 줍니다.

모델에게 문제(특징)와 정답(레이블)을 주고, 틀릴 때마다 조금씩 고치게 하는 과정입니다. 사람이 문제집을 풀고 채점하며 실력이 느는 것과 같아요.

"이 손글씨는 7이야" → 모델이 1이라고 답함 → "틀렸어!" → 모델 내부의 숫자(가중치)를 살짝 수정 → 반복.
모델 — 공부를 마친 '뇌'

학습이 끝나서 새로운 문제에 답할 수 있게 된 프로그램을 모델이라 부릅니다. 퍼셉트론도, 다층 퍼셉트론도 모두 모델입니다.

이 랩 §4.9에서 여러분이 직접 학습시키는 것이 바로 모델. 학습 후엔 여러분 손글씨도 알아봅니다.
훈련 집합 vs 테스트 집합 — 문제집과 수능

데이터를 둘로 나눕니다. 훈련 집합 = 공부용 문제집, 테스트 집합 = 한 번도 안 본 시험 문제. 공부한 문제로 시험을 보면 반칙이니까요!

이 랩은 1,797장을 60%(공부용 1,078장) : 40%(시험용 719장)로 나눕니다. 코드의 train_test_split이 이 일을 합니다.
정확률(정확도) — 시험 점수

테스트 문제 중 몇 %를 맞혔는가입니다.

719문제 중 700개 정답 → 정확률 97.4%. 이 랩 곳곳에서 "93.88%", "97.2%" 같은 숫자가 바로 이것.
가중치 — 단서마다 매기는 중요도 점수

"무게가 무거우면 사과일 가능성 ↑(중요도 +2), 표면이 노라면 배일 가능성 ↑(중요도 −1)"처럼 단서(특징)마다 붙이는 중요도 숫자가 가중치입니다. 학습 = 좋은 가중치를 자동으로 찾는 일. 이 한 문장이 이 랩 전체의 요약입니다!

§ 4.1인공 신경망의 태동

1900년대 초 뇌 과학이 발전하면서 모든 기억이 뇌에 저장된다는 사실이 밝혀졌고, 1900년대 중반에는 뇌의 정보처리 과정을 수학적으로 모델링하려는 시도가 시작됩니다. 이것이 인공 신경망artificial neural network의 태동이며, 1946년 최초의 전자식 컴퓨터 ENIAC이 등장하자 이 수학적 모델을 컴퓨터로 구현하려는 연구가 활발해집니다. 당시 가장 성공한 모델이 바로 퍼셉트론이고, 퍼셉트론은 발전을 거듭해 오늘날의 딥러닝으로 이어집니다.

§ 4.2퍼셉트론의 원리

퍼셉트론은 1958년에 탄생한 낡은 기술이지만, 딥러닝의 구성요소가 바로 퍼셉트론입니다. 또한 모델이 단순해서 기계 학습의 용어와 원리를 설명하기에 가장 좋습니다. 여기서 배우는 개념은 이후 딥러닝에 그대로 쓰이거나 일부만 변형되어 쓰입니다.

쉽게 말하면
퍼셉트론은 아주 단순한 인공 뉴런 한 개입니다. 하는 일은 딱 하나 — "여러 단서를 보고 YES냐 NO냐를 판단"합니다. 예를 들어 과일 하나를 보고 "무게가 무거울수록 +2점, 초록빛이 돌수록 −1점… 단서마다 중요도를 곱해 다 더한 점수가 기준을 넘으면 수박!"이라고 판단하는 저울인 셈이죠. 여기서 단서가 특징, 중요도가 가중치, 기준을 넘는지 판단하는 장치가 활성 함수입니다.

4.2.1구조와 연산

퍼셉트론은 입력층input layer과 출력층output layer으로 구성됩니다. 입력층에는 d+1개의 노드가 있는데, d는 특징 벡터의 차원입니다 (iris는 d=4, 8×8 필기 숫자는 d=64).

특징 벡터  x = (x1, x2, …, xd)
(4.1)

i번째 입력 노드와 출력 노드는 가중치 wi를 갖는 에지edge로 연결됩니다. 0번째 노드의 입력 x0은 항상 1이며 바이어스 노드bias node라 부릅니다. 출력 노드는 곱셈 결과를 전부 더한 s를 구하고, s를 활성 함수activation function τ에 통과시켜 출력 o를 내보냅니다.

기호를 하나씩 우리말로 바꾸면 이렇게 됩니다:

"출력 o는? → ① 1번부터 d번까지(Σ) 가중치×특징(wᵢxᵢ)을 전부 더하고 ② 거기에 w₀를 더한 값이 s. ③ s가 0보다 크면 +1, 아니면 −1이라고 답해라(τ)."

예를 들어 특징이 2개면 Σ는 그냥 w₁x₁ + w₂x₂로 풀립니다. 시그마는 덧셈 줄임표일 뿐이에요. τ(타우)는 그리스 문자로, "계단처럼 생긴 판단 함수"의 이름표입니다.

퍼셉트론은 결국 특징 벡터를 +1 또는 −1로 변환하는 장치입니다. 제품의 불량/우량, 환자/정상처럼 세상에는 두 부류로 나누는 문제가 아주 많으므로 이것만으로도 훌륭한 인식기가 됩니다.

4.2.2퍼셉트론으로 인식하기 — 예제 4-1 (OR 데이터)

크기·색상 두 특징(각각 0 또는 1)으로 제품 4개를 표현하고, 불량은 +1, 정상은 −1로 레이블링합니다.

x1=(0,0) → y1=−1,   x2=(0,1) → y2=+1,   x3=(1,0) → y3=+1,   x4=(1,1) → y4=+1

가중치가 w0=−0.5, w1=1, w2=1인 퍼셉트론에 x2=(0,1)을 넣어 보면:

o = τ(1·0 + 1·1 − 0.5) = τ(0.5) = +1  →  레이블 y2=+1과 일치, 정답!

o=0으로 두면 두 영역을 가르는 결정 경계가 나옵니다. x1+x2−0.5=0, 즉 직선 x2=−x1+0.5. 퍼셉트론은 수학적으로 특징 공간을 직선(초평면)으로 분할하는 이진 분류기이며, 결정 경계는 선형에 국한됩니다. 이 사실이 §4.7의 복선입니다.

o = τ(wxT + w0)

(4.4)

4.3.1사람의 학습 — 수영 배우기

기계 학습의 근본 원리는 사람의 학습과 닮았습니다. 수영을 배우는 과정을 알고리즘으로 써 보면:

알고리즘 4-1사람의 수영 학습
01적절한 동작을 취한다.
02while (true)
03  동작에 따라 수영을 하고 평가한다.
04  if (만족스러움) break
05  더 나은 방향으로 동작을 수정한다.
06동작을 기억한다.
알고리즘 4-2수학적 기술 — 동작을 벡터로
01초기 동작 벡터 w=(팔 속도, 팔꿈치 각도,
    팔-귀 거리)를 초기화한다.
02while (true)
03  w로 수영하고 점수 J(w)를 계산한다.
04  if (J(w)가 만족스러움) break
05  더 나은 방향 Δw를 계산한다.
06  w = w + Δw
07w를 기억한다.

예를 들어 "팔 속도는 0.5 줄이고, 팔꿈치 각도는 3° 늘리고, 팔-귀 거리는 1.2 좁힌다"면 Δw = (−0.5, 3, −1.2)이고, 다음 동작은 w + Δw가 됩니다.

알고리즘의 while·if·break가 낯설다면

알고리즘은 "일의 순서를 적은 요리 레시피"입니다. 세 가지 표현만 알면 다 읽을 수 있어요:

while (true) = "누가 멈추라고 할 때까지 계속 반복해라"
if (만족스러움) break = "만약 만족스러우면 → 반복을 그만두고 빠져나와라"
w = w + Δw = "w 상자의 값을 꺼내 Δw만큼 고친 뒤 다시 넣어라" (수학의 등식이 아니라 갱신 명령!)

Δ(델타)는 "변화량"이라는 뜻의 그리스 문자입니다. Δw = "w를 얼마나 바꿀 것인가".

4.3.2신경망의 학습 — 철저히 수학에 의존한다

알고리즘 4-3신경망의 학습 (일반 틀)
  입력: 훈련 데이터 · 출력: 최적의 매개변수 값
01난수로 매개변수 벡터 w를 초기화한다.   # 퍼셉트론이면 w = (w₀,w₁,…,w_d)
02while (true)
03  w로 데이터를 인식하고 손실 함수 J(w)를 계산한다.
04  if (J(w)가 만족스러움) break
05  J를 낮추는 방향 Δw를 계산한다.      # ★ 가장 중요한 행 — 미분을 사용한다
06  w = w + Δw
07w를 저장한다.
  • 01행 — 난수로 시작하므로 초기 성능은 형편없다. 10부류 숫자 인식이면 찍기 수준인 정확률 ≈ 10%.
  • 03행 — 손실 함수loss function J는 현재 매개변수가 범하는 오류와 비례하는 함수다.
  • 05행 — 오류를 덜 범하는 방향 Δw를 찾는 것이 핵심. 신경망은 이 방향을 미분으로 찾는다.

신경망 학습은 전형적인 최적화 문제optimization problem입니다 — "J(w)를 최소로 만드는 w를 찾아라." 구현하려면 ① 손실 함수의 정의, ② 멈춤 조건, ③ 방향 Δw를 구체화해야 합니다. 다음 절에서 하나씩 만듭니다.

§ 4.4퍼셉트론 학습 알고리즘

4.4.1손실 함수 설계

알고리즘 4-3의 03행을 구현하려면 손실 함수 J가 필요합니다. 퍼셉트론의 J는 두 조건을 만족해야 합니다.

손실 함수의 조건
① w가 훈련 집합의 샘플을 모두 맞히면(정확률 100%) J(w) = 0
② w가 틀리는 샘플이 많을수록 J(w)의 값이 크다

이 조건을 만족하는 함수 중 가장 직관적인 것:

J(w) = Σx∈I −y(wxT)
(4.5)
손실 함수가 어렵다면 — "벌점 계산기"라고 생각하자

손실 함수 J는 지금 모델이 얼마나 못하고 있는지 매기는 벌점 계산기입니다. 다 맞히면 벌점 0점, 많이 틀릴수록 벌점이 커집니다. 학습의 목표는 단 하나 — 벌점을 0에 가깝게 만드는 것.

기호 읽는 법:

x ∈ I 는 "집합 I에 속하는(∈) 샘플 x마다"라는 뜻. I는 틀린 샘플만 모아 놓은 명단이므로, 식 (4.5)는 "틀린 문제마다 틀린 정도를 점수로 매겨 전부 더해라"가 됩니다.

여기서 I는 w가 틀리는 샘플의 집합입니다. 왜 이 값이 항상 양수가 될까요? 틀린 샘플이란 레이블의 부호와 출력의 부호가 다른 샘플입니다.

  • y = +1인데 틀렸다면 wxT < 0  →  −y(wxT) = −(+1)(음수) > 0
  • y = −1인데 틀렸다면 wxT > 0  →  −y(wxT) = −(−1)(양수) > 0

따라서 식 (4.5)는 틀린 샘플이 많을수록(그리고 크게 틀릴수록) 커지고, 다 맞히면 I가 공집합이 되어 0이 됩니다. 조건 ①② 만족.

해볼 것 ① ρ=0.05로 천천히 내려가 보라 — 어느 골짜기에 도착하는가? 시작 위치에 따라 지역 최적해에 갇힐 수 있다. ② ρ를 1.0 이상으로 올려 보라 — 골짜기를 건너뛰며 발산한다. 학습률은 "보폭"이다: 너무 작으면 느리고, 너무 크면 넘어진다.

이 관찰을 수식으로 쓰면, 매개변수가 하나일 때의 학습 규칙이 나옵니다.

w1 = w1 + ρ(−∂J∂w1)
(4.6)

ρ는 학습률learning rate입니다. 미분은 방향만 알려줄 뿐 얼마나 가야 하는지는 모르므로, 작은 학습률(보통 0.001, 0.0001)을 곱해 조금씩 접근합니다. 학습률은 사람이 정하는 하이퍼 매개변수입니다.

매개변수가 여러 개면 각각으로 미분(편미분)한 값을 모은 벡터, 즉 그레이디언트gradient ∇w를 사용합니다.

w = w + ρ(−∇w),    ∇w = (∂J∂w0, ∂J∂w1, …, ∂J∂wd)
(4.7)

이제 식 (4.5)를 wi로 편미분합니다. wi가 없는 항은 상수 취급되어 사라지므로 결과가 놀랍도록 단순해집니다.

∂J∂wi = Σx∈I ∂(−y(w0+w1x1+…+wixi+…))∂wi = Σx∈I −yxi
(4.8)

식 (4.8)을 식 (4.7)에 대입하면 퍼셉트론 학습 규칙이 완성됩니다.

wi = wi + ρ Σx∈I yxi,  i = 0,1,…,d
(4.9)
행렬 표기:  w = w + ρ Σx∈I yx
(4.10)
말로 풀면
"틀린 샘플들(I)에 대해, 그 샘플의 특징 벡터를 레이블 방향으로 조금(ρ) 가중치에 더하라." +1인데 −1로 예측했다면 w를 x 쪽으로 끌어당기고, 그 반대면 밀어냅니다.

식 (4.10)을 알고리즘 4-3의 틀에 끼우면 완성된 학습 알고리즘이 됩니다.

알고리즘 4-4퍼셉트론의 학습
  입력: 훈련 집합 X, y (n은 샘플 개수) · 출력: 최적 매개변수 ŵ
01난수로 매개변수 벡터 w를 초기화한다.
02while (true)
03  I = ∅                       # 틀린 샘플을 담을 집합
04  for j = 1 to n
05    o = τ(wxjT)              # 식 (4.4) — 전방 계산(예측)
06    if (o ≠ yj) I = I ∪ {xj}   # 틀렸으면 I에 추가 — 오차 계산
07  if (I = ∅) break            # 다 맞히면(J=0) 종료
08  w = w + ρ Σx∈I yx          # 식 (4.10) — 가중치 갱신
09ŵ = w

03~08행을 한 번 돌면 훈련 집합 전체를 한 번 처리한 것입니다. 이를 한 세대epoch라 부릅니다. 단, 퍼셉트론은 선형 분리만 가능하므로 선형 분리가 불가능한 데이터에서는 I가 공집합이 될 수 없어 무한 루프를 돕니다. 실전에서는 "지정한 세대 수를 돌았는데도 I가 줄지 않으면 멈춘다"로 조건을 완화합니다.

  그 결과가 평균제곱오차MSE, Mean Squared Error:

  

    J(U1,U2) =
    1|M|
    Σx∈M
    ‖y − τ2(U2τ1(U1xT))‖2
  
(4.19)

    10개의 전구 중 정답 전구만 켠 모습입니다.

미니배치: 샘플을 한 묶음(예: 32장)씩 모아서 처리하는 것.
    설거지를 접시 한 장씩 하지 않고 한 아름씩 모아 하는 것과 같습니다 — 훨씬 빠릅니다.

    제곱하는 이유는 ① 음수/양수 오차가 상쇄되지 않게, ② 크게 틀린 것에 더 큰 벌점을 주려고.

  


  
4.8.2학습 알고리즘 — 오류를 뒤로 흘려보낸다

  
최적화할 매개변수가 w 하나에서 행렬 둘(U¹, U²)로 늘었을 뿐, 갱신 규칙은 식 (4.7)과 똑같은 꼴입니다.

  

    U2 = U2 + ρ(−∇U2),  
    U1 = U1 + ρ(−∇U1)
  
(4.20)

  
∇U²와 ∇U¹은 각 가중치로 J를 편미분한 값(∂J/∂u²kj, ∂J/∂u¹ji)을 행렬로 모은 것입니다.
  중요한 것은 갱신 순서: 오차에서 가까운 U²를 먼저 갱신하고, 그 결과를 이용해 U¹을 갱신합니다.
  오류가 출력에서 입력 쪽으로 역방향 전파되므로 이 절차를
  오류 역전파error backpropagation 학습 알고리즘이라 부릅니다.
