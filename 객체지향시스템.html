Chapter 01 at a glance

C#은 마이크로소프트가 2000년에 발표한 완전한 객체지향 언어다. 소스 코드(.cs)는 빌드를 거쳐야 실행 파일(.exe)이 되므로, 한 글자라도 고쳤으면 반드시 다시 빌드해야 한다. 개발 도구는 무료인 Visual Studio Community.

쉽게 말하면변수는 이름표 붙은 컵. int a;는 컵 꺼내기, a = 100;은 컵에 붓기. 단 진짜 컵과 달리 result에 부어도 a, b의 값은 그대로 남는다(값이 복사되기 때문, 교재 '여기서 잠깐').
정수 나눗셈 — int / int는 소수점 이하를 버린 몫이다. 100/50은 2, 1234/456은 2, 200/400은 0. 그리고 코드의 따옴표는 곧은 따옴표(") — 둥근 따옴표(“ ”)가 섞이면 컴파일 오류.

ReadLine으로 키보드 값 받기 — 문자열을 정수로

실습 2-5 · 소스 2-2 · 2-3 (Project02_2)
str = Console.ReadLine(); a = Convert.ToInt32(str);
ReadLine은 Enter까지 한 줄을 받는데 무조건 문자열로 준다. 계산하려면 Convert.ToInt32()로 정수로 바꾼다.
static void Main(string[] args)
{
    int a, b;
    int result;

    string str;

    Console.Write("첫번째 계산할 값을 입력하세요 ==> ");
    str = Console.ReadLine();
    a = Convert.ToInt32(str);

    Console.Write("두번째 계산할 값을 입력하세요 ==> ");
    str = Console.ReadLine();
    b = Convert.ToInt32(str);

    result = a + b;
    Console.WriteLine(a + "+" + b + "=" + result);

    result = a - b;
    Console.WriteLine(a + "-" + b + "=" + result);

    result = a * b;
    Console.WriteLine(a + "*" + b + "=" + result);

    result = a / b;
    Console.WriteLine(a + "/" + b + "=" + result);
}
메서드출력 후 줄바꿈주 용도
Console.WriteLine()한다결과를 한 줄씩 출력

출력은 {순번,폭:서식}으로 자리를 잡는다 — {0}은 첫 번째 값의 자리, D는 정수, F는 실수, 콤마 뒤 숫자는 칸 수. 값은 알맞은 데이터형의 그릇(변수)에 담고, 2·10·16진수는 같은 값을 보여 주는 방식일 뿐이다. 정수 ÷ 정수는 정수라는 함정까지 챙기면 이 장은 끝.

폭을 정해 줄 맞추기 — {0,5:D5} · {0,8:F1} · {0,8:S}

소스 3-8 · 그림 3-5~3-7 · 교재 p.100~101
{순번,폭:서식}
폭(콤마 뒤)은 전체 칸 수 — 칸을 먼저 잡고 오른쪽에 붙여 출력. 서식 뒤 숫자(D5, F1)는 숫자 자릿수 — D5는 빈 자리를 0으로, F1은 소수 한 자리(반올림).
Console.WriteLine("{0,5:D}", 123);      // "  123"
Console.WriteLine("{0,5:D5}", 123);     // "00123"
Console.WriteLine("{0:F}", 123.456);    // "123.46"
Console.WriteLine("{0,8:F1}", 123.456); // "   123.5"
Console.WriteLine("{0,8:F4}", 123.456); // "123.4560"
Console.WriteLine("{0,8:S}", "CSharp"); // "  CSharp"
쉽게 말하면폭은 주차 칸, 값은 차. 5칸 구역에 3칸짜리 차를 오른쪽 벽에 붙여 대면 왼쪽 2칸이 빕니다. 폭에 음수({0,-8})를 주면 왼쪽 벽에 붙어요. 문자열의 :S는 사실 무시되고 폭만 적용됩니다.

static void Main(string[] args)
{

    for (int i = 0; i < 5; i++)

        Console.Write("취득 점수 " + score + " ==> ");

        if (score >= 90)
            Console.Write("A");
        else if (score >= 80)
            Console.Write("B");
        else if (score >= 70)

switch (값) { case 1: … break; case 2: … break; default: … break; }
값과 같은 case로 바로 이동해 실행하고 break에서 빠져나간다. 어느 case에도 맞지 않으면 default. case 뒤는 콜론(:)이다.
static void Main(string[] args)
{
    int a;

    Console.Write("1 ~ 4 중에 선택하세요 : ");
    a = int.Parse(Console.ReadLine());

    switch (a)
    {
        case 1:
            Console.WriteLine("1을 선택했다.");
            break;
        case 2:
            Console.WriteLine("2를 선택했다.");
            break;
        case 3:
            Console.WriteLine("3을 선택했다.");
            break;
        case 4:
            Console.WriteLine("4를 선택했다.");
            break;
        default:
            Console.WriteLine("이상한 것을 선택했다.");
            break;
    }
}

3을 입력하면 case 3:으로 곧장 가서 3을 선택했다.를 찍고 끝난다. case 1·2는 검사조차 하지 않는다(교재 그림 5-10). 7을 넣으면 이상한 것을 선택했다.

Chapter 06 at a glance

같은 문장을 백 번 복사하는 대신 반복문에 맡긴다. for 문은 초깃값 → 조건식 → 반복할 문장 → 증감식 순서로 돌고, 초깃값은 딱 한 번만 실행된다. for·while은 조건을 먼저 검사하므로 0번 실행될 수 있고, do~while은 나중에 검사하므로 최소 1번 실행된다. 반복을 끊을 때는 break, 이번 바퀴만 건너뛸 때는 continue. 이 장의 완성 작품은 가로 구구단과 별표 마름모다.

반복문이 필요한 이유와 for 문의 세 칸

초깃값 · 조건식 · 증감식 — 세미콜론 두 개로 나눈다

[소스 6-1]은 같은 Console.WriteLine()을 세 번 복사했다. 백 번, 천 번이라면 복사로는 무리다. [소스 6-2]는 같은 결과를 한 줄로 낸다.

int i;
for (i = 0; i < 3; i++)
{
    Console.WriteLine("for 문을 공부 중입니다. ^^");
}
❶ 초깃값 → ❷ 조건식 → ❸ 반복할 문장 → ❹ 증감식 → ❷ 조건식 …
초깃값은 맨 처음 한 번만. 조건식이 거짓이 되는 순간 ❺ for 문을 빠져나간다. 증감식은 조건 확인 직후가 아니라 반복할 문장을 실행한 뒤에 돈다.
단계실행하는 부분실행 뒤 ii < 3일어나는 일
1❶ i = 00–준비
2 · 3 · 4❷ → ❸ → ❹0 → 1참1번째 출력 후 i++
5 · 6 · 7❷ → ❸ → ❹1 → 2참2번째 출력 후 i++
8 · 9 · 10❷ → ❸ → ❹2 → 3참3번째 출력 후 i++

쉽게 말하면운동장 돌기다. 출발선에 한 번 서고(❶), 돌 때마다 "아직 3바퀴 안 됐나?" 묻고(❷), 한 바퀴 뛰고(❸), 바퀴 수를 센다(❹). 세 번이니까 i <= 3이라고 쓰기 쉽지만, 0부터 시작하므로 그러면 네 번이 된다.
조건식은 먼저 검사한다 — 초기식을 i = 3으로 바꾸면 i < 3이 곧바로 거짓이라 반복할 문장은 한 번도 실행되지 않는다. 그리고 중괄호가 없으면 바로 아래 한 문장만 반복된다([소스 6-3]). 들여쓰기는 C#에게 아무 의미가 없다.

static void Main(string[] args)
{
    string str;
    int lowerCnt = 0, upperCnt = 0, numCnt = 0, hanCnt = 0, etcCnt = 0;

    Console.Write("문자열 입력 ==> ");
    str = Console.ReadLine();

    foreach (char c in str)
    {
        if ('a' <= c && c <= 'z')
            lowerCnt++;
        else if ('A' <= c && c <= 'Z')
            upperCnt++;
        else if ('0' <= c && c <= '9')
            numCnt++;
        else if ('가' <= c && c <= '힣')
            hanCnt++;
        else
            etcCnt++;
    }
    Console.WriteLine("소문자:{0}, 대문자:{1}, 숫자:{2}, 한글:{3}, 기타:{4}", lowerCnt, upperCnt, numCnt, hanCnt, etcCnt);

    Console.WriteLine();
    Console.Write("거꾸로 출력 ==> ");
    for (int i = str.Length -1; i >= 0 ; i--)
        Console.Write(str[i]);
    Console.WriteLine();
}

private void tbar_image_Scroll(object sender, EventArgs e)
{
    Bitmap bitmap = new Bitmap(pb_image.Image);
    int R,G,B;
    Color c;

    for (int i = 0; i < bitmap.Height; i++)
    {
        for (int k = 0; k < bitmap.Width; k++)
        {
            c = bitmap.GetPixel(k, i);
            R = c.R + tbar_image.Value;
            G = c.G + tbar_image.Value;
            B = c.B + tbar_image.Value;
            if (R > 255)
                R = 255;
            else if (R < 0)
                R = 0;
            if (G > 255)
                G = 255;
            else if (G < 0)
                G = 0;
            if (B > 255)
                B = 255;
            else if (B < 0)
                B = 0;
            c = Color.FromArgb(R, G, B);
            bitmap.SetPixel(k, i, c);
        }
    }

}
